## 1. معمارية تطبيق سطح المكتب (Desktop Architecture)

تم تطوير تطبيق سطح المكتب لـ **EduCenter ERP** كحزمة متكاملة لنظام التشغيل **Windows** تعتمد على إطار عمل **Electron 33** مع تطبيق أعلى معايير العزل والأمان (`Context Isolation = true` و `Node Integration = false`).

### 1.1. الهيكل الداخلي لتطبيق سطح المكتب (`apps/desktop`)
```text
apps/desktop/
├── src/
│   ├── main/
│   │   ├── index.ts              # نقطة الدخول وإنشاء نافذة العرض الرئيسية
│   │   ├── ipc-handlers.ts       # تسجيل ومعالجة قنوات الاتصال IPC المعقمة
│   │   ├── server-manager.ts     # إدارة تشغيل وإيقاف خادم API المحلي كـ Child Process
│   │   ├── printer-manager.ts    # إدارة الطابعات والطباعة الحرارية المباشرة والصامتة
│   │   ├── store-manager.ts      # إدارة حفظ الإعدادات المحلية (config.json) مع التعافي التلقائي
│   │   ├── network-utils.ts      # فحص واجهات الشبكة وفحص الاتصال (Ping)
│   │   └── package-config.ts     # قراءة إصدار التطبيق وهوية الحزمة
│   └── preload/
│       ├── index.ts              # جسر الأمان ContextBridge وتمرير واجهة desktopApi
│       └── desktop-api.types.ts  # عقود وأنواع قنوات الـ IPC والبيانات المتبادلة
```

## 2. أوضاع التشغيل والربط الشبكي المحلي (Operating Modes & Local Network)

صُمم النظام ليعمل بكفاءة مطلقة في بيئة السناتر التعليمية التي قد تعمل داخل شبكة محلية معزولة (Local LAN / Offline) أو متصلة بالإنترنت:

```
    ┌────────────────────────────────────────────────────────┐
    │          جهاز الخادم الرئيسي (Server Mode)             │
    │  - يعمل عليه تطبيق سطح المكتب كخادم رئيسي              │
    │  - يستضيف قاعدة البيانات وخادم الـ API                  │
    │  - العنوان المحلي: http://192.168.1.15:4000           │
    └───────────────────────────┬────────────────────────────┘
                                │
          شبكة السنتر المحلية (Local Area Network / Wi-Fi)
                                │
        ┌───────────────────────┴───────────────────────┐
        ▼                                               ▼
┌───────────────────────────────┐       ┌───────────────────────────────┐
│  جهاز الاستقبال (Client Mode)  │       │    جهاز الخزينة (Client Mode) │
│ - يتصل بـ 192.168.1.15:4000  │       │ - يتصل بـ 192.168.1.15:4000  │
│ - رصد الحضور وطباعة الكروت    │       │ - تحصيل الدفعات وطباعة الفواتير│
└───────────────────────────────┘       └───────────────────────────────┘
```

### 2.1. وضع الخادم الرئيسي (`Server Mode`)
- يُفعل على الجهاز الرئيسي للمركز؛ حيث يقوم التطبيق بتشغيل خادم الـ API وربطه بقاعدة البيانات المحلية.
- **الاكتشاف التلقائي لعنوان الشبكة (`Auto-Discovery`):**  
  يقوم التطبيق آلياً بفحص بطاقات الشبكة المتصلة (`network-utils`) واستخراج كافة عناوين IPv4 المحلية للجهاز (مثل `192.168.1.15`) وعرضها في نافذة الإعدادات بوضوح لتسهيل ربط باقي أجهزة موظفي السنتر.

### 2.2. وضع العميل الفرعي (`Client Mode`)
- يُثبت على أجهزة موظفي الاستقبال، الكاشير، وشؤون الحضور داخل السنتر.
- يُدخل الموظف عنوان خادم السنتر في الشبكة المحلية (مثل `http://192.168.1.15:4000`).
- **فحص الاتصال اللحظي (`Connection Ping`):**  
  يتضمن التطبيق أداة اختبار اتصال مدمجة تفحص جاهزية الخادم وزمن الاستجابة قبل الحفظ، مع إشعار المستخدم فوراً في حال وجود انقطاع في الشبكة أو خطأ في العنوان.

## 3. محرك الطباعة الحرارية الصامتة المباشرة (Direct Silent Printing Engine)

تعتبر سرعة طباعة إيصالات السداد عنصراً حاسماً في أوقات ذروة توافد الطلاب لمنع التكدس أمام الخزينة.

### 3.1. آلية الطباعة الصامتة (`Direct Silent Print`)
- **تخطي مربع حوار الطباعة:** على عكس المتصفحات العادية التي تفتح نافذة الطباعة وتتطلب نقرات إضافية، يقوم تطبيق سطح المكتب بإرسال أمر الطباعة مباشرة إلى الطابعة الحرارية دون أي مقاطعة للمستخدم (`silent: true`).
- **معيار الورق الحراري (80 ملم):**  
  يتم توليد صفحة HTML مصممة خصيصاً بمقاس رول الفواتير الحرارية القياسي (`80mm width`) متضمنة شعار السنتر، الاسم الرسمي، رقم الإيصال المشفر، تفاصيل المجموعات، المبلغ المسدد، وتاريخ وساعة العملية.
- **نافذة طباعة مخفية في الخلفية (`Offscreen Printing Window`):**  
  يقوم `printerManager` بإنشاء نافذة متصفح غير مرئية في الذاكرة، تحميل محتوى الإيصال فيها، إرسال أمر الطباعة المباشر إلى الطابعة المحددة، ثم تدمير النافذة فوراً لتحرير الذاكرة.

### 3.2. إدارة واختيار الطابعات
- يتيح التطبيق عبر قناة `desktop:get-printers` استعراض كافة الطابعات المثبتة على نظام Windows واختيار الطابعة الافتراضية للفواتير الحرارية وحفظها في إعدادات التطبيق.
- **التوافق التلقائي في بيئة الويب:** في حال فتح النظام من متصفح ويب عادي (مثل Chrome خارج تطبيق الديسكتوب)، يتعرف النظام تلقائياً على البيئة ويوفر للمستخدم زر الطباعة القياسي (`window.print()`) بسلاسة تامة.

## 4. قنوات الاتصال الداخلي (`Desktop IPC Channels`)

يوفر كائن `window.desktopApi` عبر الـ `Preload Script` دوالاً آمنة ومحددة بدقة للتفاعل بين الواجهة الأمامية ونظام التشغيل:

| اسم القناة (`DESKTOP_CHANNELS`) | نوع العملية | الوظيفة والبيانات |
| :--- | :--- | :--- |
| **`desktop:get-config`** | استعلام (`Invoke`) | قراءة الإعدادات المحفوظة (الوضع، الرابط، الطابعة الافتراضية) |
| **`desktop:save-config`** | تنفيذ (`Invoke`) | حفظ تحديثات الإعدادات بعد تعقيمها والتحقق منها |
| **`desktop:get-local-ips`** | استعلام (`Invoke`) | إرجاع قائمة عناوين IPv4 لبطاقات الشبكة المحلية النشطة |
| **`desktop:test-connection`** | تنفيذ (`Invoke`) | فحص الاتصال مع رابط خادم محدد وإرجاع حالة النجاح والزمن |
| **`desktop:get-server-status`**| استعلام (`Invoke`) | فحص حالة خادم الـ API المحلي (`RUNNING`, `STOPPED`, `ERROR`) |
| **`desktop:start-server`** | تنفيذ (`Invoke`) | بدء تشغيل خادم الـ API المحلي |
| **`desktop:stop-server`** | تنفيذ (`Invoke`) | إيقاف خادم الـ API المحلي وإنهاء عمليته بأمان |
| **`desktop:get-printers`** | استعلام (`Invoke`) | الحصول على قائمة الطابعات الموصولة بنظام Windows |
| **`desktop:print-receipt`** | تنفيذ (`Invoke`) | إرسال أمر طباعة صامت للإيصال مع تمرير كود الـ HTML |
