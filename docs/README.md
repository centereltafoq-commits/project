# الدليل الفني الشامل والموسوعة التوثيقية لنظام إدارة السنتر التعليمي (EduCenter ERP)

مرحباً بك في البوابة التوثيقية الرسمية الشاملة لنظام **EduCenter ERP** — المنظومة المتكاملة لإدارة السناتر التعليمية والمراكز الأكاديمية والدروس الخصوصية.

تم إعداد هذه الوثائق بدقة هندسية ورياضية فائقة لتعكس الكود الفعلي المطبق في بيئة الإنتاج بنسبة 100%، وتغطي كافة التفاصيل المعمارية، المحاسبية، التشغيلية، الأمنية، وقواعد البيانات.

## 💡 مبادئ التشغيل الذهبية (Core Operational Rules)

1. **الصرامة المحاسبية والحماية التاريخية:**  
   لا يمكن بأي حال من الأحوال تعديل أسعار أو حصص أو مستحقات أي شهر تم إغلاقه مالياً (`isClosed = true`). يتم تجميد كافة أرقام الشهر فور إغلاقه، وتُرفض أي معاملة جديدة عليه بخطأ `409 Conflict`.
2. **صمام أمان بدء العام الجديد:**  
   لا يمكن تشغيل تصفير العام الدراسي إلا بعد نجاح النسخة الاحتياطية المسبقة بنسبة 100% وإدخال رمز الأمان PIN الصحيح بمقارنة آمنة زمنياً.
3. **معيار التصفح والبحث:**  
   كل جدول في النظام يلتزم بعرض 25 سجلاً افتراضياً مع ترقيم على مستوى السيرفر لحماية الذاكرة وضمان سرعة الاستجابة مهما بلغ عدد الطلاب أو العمليات.
